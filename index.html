Python · Raspberry Pi · RP2040 · LCM · PID · Onshape

Self-Balancing Omnidirectional Ball-Bot

Designed and built a three-omni-wheel ball-bot: mechanical assembly, 3D-printed parts, and the kinematic mapping from body motion to individual wheel commands. A 100 Hz multithreaded control pipeline links a Raspberry Pi and an RP2040 over LCM for sensor acquisition, state estimation, and motor actuation. I implemented and experimentally compared feedforward, PID, and combined feedforward + PID wheel-speed control using encoder feedback.

AUV Navigation · CSAC Timing · Acoustic Modems · Embedded

Under-Ice AUV Navigation (ROBEX Research)

Research in the Robotic Exploration Lab on navigating autonomous underwater vehicles beneath ice, where GPS is unavailable. Our team is building One-Way Travel Time acoustic navigation: Chip-Scale Atomic Clocks keep a beacon and the vehicle synchronized, so range can be computed from how long each acoustic ping takes to arrive. I evaluate low-frequency transducers and Popoto modems and configure the embedded computers that capture acoustic payload data for onboard processing.

  • Ongoing lab research · code not public

C++ · Eigen · RIX Middleware

Inverse Kinematics Solver & RIX Service

A numerical inverse-kinematics solver in C++ that uses Eigen to compute the geometric Jacobian's pseudo-inverse and converges on joint configurations by gradient descent. It runs behind iksrv, an asynchronous service node on the RIX middleware that accepts motion-planning requests and returns joint-configuration trajectories.
